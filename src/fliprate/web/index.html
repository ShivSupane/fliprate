    What is FlipRate?

    FlipRate measures how often an NLP model changes its answer when the same message is typed differently. People write "nahi", "nhi", "nahin" and "avadlaaa" for the same meaning. Many models answer differently for each. FlipRate calls this a flip.

    A safe variant is a rewritten version of a message that provably keeps the same words (up to reviewed equivalent spellings) and the same negations. Flip rate is the share of safe variants for which the model's answer differs from its answer on the original.

    Flip rate measures instability, not wrongness. A model can flip toward the right answer.

    Gate decisions

    DecisionMeaning
    PASS Stable across safe variants (or mostly stable, with a warning listing what flipped).
    TRANSFORM Some variants flip, and approved normalization makes the pipeline stable. The cleaned text is used; the original is kept.
    REVIEW Empty input, mostly non-Latin script, or unstable and normalization does not fix it. Route to a human.

    Change types tested

    • spelling — swaps a word for another member of its safe-spelling group (e.g. "bahut" ↔ "bohot" ↔ "bhut")
    • repetition — stretches a vowel ("nahi" → "naahii", simulating emphasis)
    • punctuation — strips or doubles trailing punctuation
    • case — lowercases, uppercases, or capitalises the whole message

    API

    • POST /jobs/analyze — start a gate analysis, returns {"job_id":"…"}
    • POST /jobs/test — start a robustness test (optional rows array)
    • GET /jobs/{id}/stream — Server-Sent Events stream of progress
    • GET /health — {"status":"ok"}
    • GET /ready — 503 until model is warmed up
    • GET /metrics — Prometheus counters

    Set FLIPRATE_API_KEY to require a key on POST endpoints. Set FLIPRATE_MODEL=pkg:fn to use your own model.
